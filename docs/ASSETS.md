# 素材来源、许可证与使用限制

| 资源 | 来源 | 许可/限制 | 状态 |
|---|---|---|---|
| `assets/heroine.jpg` | 用户在本会话上传的参考插画 | 用户自有/提供；仅用于本项目的对话立绘与配色参考，不作为 3D 模型贴图 | 已使用 |
| `vendor/three.module.js` 及 `vendor/jsm/**` | npm 包 `three@0.180.0`（MIT License） | MIT，可商用，需保留版权声明；本地副本来自 `node_modules/three` | 已使用 |
| 主角三维模型 | **程序化临时占位资源**，由本项目代码用几何体生成 | 无第三方素材；**不是最终角色建模**，不得对外宣称已完成 anime 角色模型 | 占位 |
| 建筑 / 街道 / 树木 / 街灯 / 车辆 / NPC 模型 | **程序化生成**，由本项目代码构建 | 原创代码生成，无第三方模型 | 已使用 |
| 窗户与招牌贴图 | 运行时 Canvas 生成 | 原创生成，无第三方图片 | 已使用 |
| 字体 | 浏览器系统字体（Noto Sans SC / Microsoft YaHei 回退） | 系统字体，不随项目分发 | 已使用 |

## 明确未使用

- 未使用任何第三方 3D 模型、HDRI、商业字体或受版权保护的插画作为场景贴图。
- 未将二维立绘贴到平面模型上冒充 3D 角色。
- 未使用 CDN 外链资源（全部本地化）。
