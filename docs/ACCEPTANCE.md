## 明确未完成 / 未验证

1. 最终 anime 角色建模与骨骼绑定（当前为程序化占位模型）。
2. 完整 200m×200m 城市密度（当前为精品街角 + 周边街区 + 远景剪影）。
3. 其余四章剧情与三结局迁移（数据保留在 2D 原型中）。
4. GTX 1660 / 1080p / 30FPS 实测与低画质基准。
5. Windows 独立打包（exe / 安装包 / 自动更新）。
6. Godot 4 正式引擎迁移（未安装引擎，等待用户确认）。
7. 接触阴影、色彩分级 LUT、动态分辨率。
8. 长时间运行稳定性、显存/内存占用测试。

## 已知限制

- 通过 HTTP 服务运行（`python -m http.server 8123`），不能直接用 `file://` 双击打开（ES Module 限制）。
- 指针锁定需要用户点击画面；无头截图无法模拟真实鼠标操作。
- NPC 使用硬编码巡逻点与简化状态机，没有寻路网格。
